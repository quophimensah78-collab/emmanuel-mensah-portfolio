Emmanuel Mensah Portfolio - Outside ChatGPT Hosting

This folder is a normal static website.

Files to upload:
- index.html
- styles.css
- script.js
- assets/

How to publish:
1. Choose a host such as GitHub Pages, Netlify, Vercel, Namecheap/cPanel, or a university web space.
2. Upload everything in this folder.
3. Make sure index.html stays at the top level next to styles.css, script.js, and the assets folder.
4. Open the public URL from your host.

This version is not tied to chatgpt.site.
